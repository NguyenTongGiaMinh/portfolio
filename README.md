## 9. Local Development & Deployment

### Run Locally:
```bash
# Clone the repository
git clone https://github.com/MinTongGia/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build:
```bash
npm run build
npm run preview
```

### Deploy to Vercel:
The project includes `vercel.json` and is optimized for zero-configuration continuous deployment on Vercel:
1. Import `https://github.com/MinTongGia/portfolio` in the [Vercel Dashboard](https://vercel.com/new).
2. Framework Preset: **Vite** (detected automatically).
3. Build Command: `npm run build`.
4. Output Directory: `dist`.
5. Click **Deploy**.
